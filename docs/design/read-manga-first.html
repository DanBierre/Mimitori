Read, manga first

Three ways to put manga and PDFs up front on the Read page. Same look, different layouts. Flip on the drag state to see the drop target light up.

1

Book on top

One column, flipped. The book drop leads with a drawn page and a boxed bubble, so the first thing you see says what the app does. Recent books sit under it as a shelf of covers. Paste moves below a hairline. Smallest change from today.

Phone

2

Two doors

Book and text side by side, equal height, split by a hairline. Book is on the left, so you read it first. Recent books are a ruled list under the drop. On phones the book door stacks on top. Best for desktop, where the space is.

Desktop

Phone

3

A switch, book first

A Book / Text switch under the heading, book chosen by default. Only one thing shows at a time, so the drop target gets the whole page. Recent books are an Instrument readout table. The app remembers the last side you used. Try the switch.
